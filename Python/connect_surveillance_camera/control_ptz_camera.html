1. PTZ カメラ (WV-S61702-Z3) を Python プログラムで制御する 🔗

ここでは cgi コマンド /cgi-bin/absctrl を使用して実現してみます。

 

注意

ID, パスワード, カメラのIPアドレスは例です。

あなたが使用する環境に合わせて変更してください。

 

 

CURL コマンド例： 🔗 

curl --digest -u admin:Admin12345 "http://192.168.0.11/cgi-bin/absctrl?pan=0&tilt=800&zoom=0"

 

Python プログラム例： 🔗 

'''
値範囲：
PAN:     0 to 3599
TILT: -300 to 900
ZOOM:   10 to 6400

WV-S61702-Z3 でテスト

環境構築：
1. Python をインストール
2. requests ライブラリをインストール (`pip install requests`)
3. カメラの IP アドレス、ユーザー名、パスワードを設定
'''

import requests
from requests.auth import HTTPDigestAuth

CAMERA_IP = "192.168.0.11"
USER      = "admin"
PASSWORD  = "Admin12345"
PAN       = 600
TILT      = 900
ZOOM      = 0

url = (
    f"http://{CAMERA_IP}/cgi-bin/absctrl?pan={PAN}&tilt={TILT}&zoom={ZOOM}"
)

response = requests.get(
    url,
    auth=HTTPDigestAuth(USER, PASSWORD)
)

print(response.status_code)
print(response.text)
